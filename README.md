# Java Control Flow Exercises

Консольные упражнения по циклам и управлению потоком выполнения.

## Сценарии
- определение пятниц месяца;
- моделирование прохождения марафонской дистанции;
- расчёт дней парковки с использованием `while`, `for` и `do-while`.

## Технологии
Java, циклы, арифметика и условные операторы.

## Запуск
Требуется JDK. Запустите класс `Main` из `src/Main.java` в IntelliJ IDEA.

Учебные консольные задачи. Похожая копия обнаружена в приватном репозитории `DZ9_`.
